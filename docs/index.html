Up and running in 10 seconds

Install, point it at any repo, and explore.

# install
pip install git+https://github.com/androvonx95/vantage.git

# launch the dashboard
vantage

# generate an interactive knowledge graph
vantage map   # -> ./vantage-map.html

# security & quality scan
vantage scan

# git intelligence
vantage insights

# optional: enable local AI
ollama pull llama3.1
vantage ai setup
git diff | vantage ai review -
